# SRT ホワイトボードアニメ Skill

SRT 字幕を、物語の順序に沿って描画されるホワイトボード手描き動画へ変換する Skill です。**領域分割マスクによる演出制御**と**ストリーミング筆跡描画**を組み合わせており、各要素が字幕に合わせて順番に登場し、ペン先が領域内で連続して線を引き、そこへ段階的に彩色して、最終的に MP4 として書き出します。

知識解説、ストーリーの語り、講座の字幕、ショート動画の台本などを、暖かいベージュの紙地に描かれた手描きアニメに仕上げる用途に向いています。

## サンプル

**シーン: 猿山でバナナの奪い合い** —— 字幕の語りの順序に従って、築山と子ザル、バナナを奪う大ザル、そして見物する子どもたちを順に描いていきます。

![猿山でバナナの奪い合い: SRT ホワイトボードアニメのデモ](examples/scene-01-monkey-mountain-stream.gif)

元の線画: [PNG を見る](examples/scene-01-monkey-mountain.png)。

## 主な機能

- SRT 字幕を解析し、推奨される 25〜35 秒の長さでシーンに分割する
- まず絵コンテと作画方針を出力し、1 カットで伝える内容を 1 つに絞る
- 画面上の座標ではなく字幕のイベントを基準に、要素の意味的な描画順序を組み立てる
- `annotation.json` で領域・タイミング・字幕との対応・重なりの保護領域を管理する
- 各領域を連続したストリーミング筆跡で描画する。まず `ink` で線画を引き、続いて `color` で彩色する
- ブラウザのプレビューツールで領域・順序・時間・字幕との対応を調整できる
- カットごとのレンダリングと複数カットの結合に対応し、完全な MP4 を出力する

## 動作の流れ

この Skill の要は「字幕駆動・段階的な確認」です。各ステップの完了ごとに確認を待つことで、絵コンテ・線画・アノテーションが固まらないうちにレンダリングのコストを浪費することを防ぎます。

1. SRT を解析し、絵コンテと作画方針を出力する。
2. 確認後、統一されたスタイルの線画を生成する。
3. 線画を確認したら、字幕と元画像をもとにアノテーションを作成し、プレビューツールに読み込む。
4. アノテーションを確認後、領域分割と描画方向のチェック画像を生成する。
5. プレビューツールで領域・語りの順序・タイミング・字幕との対応を調整して保存する。
6. 最終的なアノテーションを確認したら、カットごとに MP4 をレンダリングする。
7. 複数カットのプロジェクトは、各カットの完成動画を確認してから結合する。

## ビジュアル規約

- 暖かいベージュの紙の背景: 推奨は `#F5EBD7`
- 濃いグレーのスケッチ線。赤・オレンジ・青は概念を示すワンポイントとして少量のみ使用する
- ミニマルな手描き、すっきりした背景、十分な余白
- シーン内の文字、ラベル、写真的な表現、3D 効果、複雑なテクスチャは使わない

## インストールと環境構築

Skill には独立した Python 仮想環境を用意するスクリプトが同梱されています。初回実行時は次のコマンドを実行してください。

```bash
python scripts/prepare_env.py --check
python scripts/prepare_env.py
```

成功すると 1 つ目のコマンドが `ENV_PY=<パス>` を出力します。以降のレンダリングではこのインタープリタを使い、依存関係を隔離してください。

## プロジェクト素材の構成

```text
assets/whiteboard/<プロジェクト名>/
├── scene-01-<名前>.png
├── scene-01-<名前>.annotation.json
├── scene-01-<名前>-whiteboard.mp4
└── scene-01-<名前>-preview.mp4
```

画像とアノテーションは同名にする必要があります。たとえば `scene-01-demo.png` には `scene-01-demo.annotation.json` が対応します。

## アノテーション形式

各要素には元画像の整数ピクセル座標を使い、`sequence`、`subtitle`、`narrativeRole` を通じて字幕中のイベントと紐付けます。領域は「シーンの状況説明 → 主要な人物・物体 → 動作や変化 → 反応・結果」の順に並べます。

```json
{
  "sceneId": "scene-01",
  "canvas": { "width": 1672, "height": 941 },
  "storyBasis": "子ザルが猿山の上でバナナを持っていると、大ザルがバナナを奪い取り、子どもたちがそれを横で見ている。",
  "sceneDurationMs": 9000,
  "elements": [
    {
      "id": "rockery",
      "label": "猿山のシーン",
      "sequence": 1,
      "narrativeRole": "物語の状況説明",
      "subtitle": "子ザルが猿山のてっぺんに座り、手にバナナを持っている。",
      "type": "structure",
      "region": { "x": 20, "y": 120, "width": 540, "height": 780 },
      "reveal": {
        "direction": "top_to_bottom",
        "startMs": 300,
        "durationMs": 2600,
        "maskPaddingPx": 22,
        "protectedRegions": []
      },
      "handPath": { "start": [290, 130], "end": [290, 890], "easing": "easeInOut" }
    }
  ]
}
```

`direction` と `handPath` はプレビューツールの矩形プロキシに使われます。完成動画の実際の筆跡は、ストリーミング描画エンジンが自動生成します。互いに重なり合うオブジェクトについては、先に描かれる要素の `protectedRegions` に表示を遅らせたい領域を指定し、後から描く内容が先に見えてしまうのを防ぎます。

## よく使うコマンド

字幕を解析して絵コンテ案を生成する:

```bash
python scripts/parse_srt.py <字幕.srt> --target-sec 30 --min-sec 25 --max-sec 35
```

領域チェック画像を生成する:

```bash
python scripts/render_annotation_preview.py <画像パス> <アノテーションパス> <プレビュー画像の出力パス>
```

`assets/preview.html` を開き、「フォルダを開く」からシーンのディレクトリを読み込むと、領域・順序・時間・字幕との対応を編集できます。

単一カットをレンダリングする:

```bash
<ENV_PY> scripts/render_stream_whiteboard.py <画像パス> <アノテーションパス> <出力.mp4> assets/drawing-hand.png \
  --ink-path grid --color-fill contour-wipe
```

複数カットを結合する:

```bash
<ENV_PY> scripts/merge_scenes.py --inputs カット1.mp4 カット2.mp4 カット3.mp4 --output final.mp4
```

## 品質チェック

- 最初のフレームがきれいな暖色ベージュの紙地で、線が先に見えていないこと
- `canvas` が元画像のサイズと一致し、すべての領域がキャンバス内の整数ピクセル座標であること
- `sequence` と `startMs` が字幕の語りの順序と一致していること
- 途中のフレームで、まだ開始していない領域や保護領域が先に現れないこと
- ペン先が現在のストリーミング筆跡に寄り添っていること。線画がはっきりしている場合は `--ink-path skeleton` を選ぶこともできる
- 各カットの終了後、完成画面を最低 0.5 秒は静止させること。複数カットの結合順序が字幕の絵コンテと一致していること
